# Sistema de Detección de Códigos Farmacéuticos

Aplicación avanzada para detección automática de códigos de barras en cupones farmacéuticos usando YOLO v10 y computer vision.

## Características

- **Detección automática** con YOLO v10
- **Procesamiento avanzado** con OpenCV y gradientes
- **Validación CIMA** integrada
- **Interfaz moderna** con Streamlit
- **Análisis en tiempo real** de códigos farmacéuticos

## Uso

1. Sube imágenes de cupones farmacéuticos
2. El sistema detecta automáticamente los códigos de barras
3. Valida los resultados con la base de datos CIMA española

Desarrollado para análisis profesional de códigos farmacéuticos en España.
